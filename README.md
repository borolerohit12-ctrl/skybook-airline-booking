# SkyBook — Airline Booking System

React + Vite single-page application for the FSJP assignment.

## Features
- Search sample flights by departure and destination
- Departure date and passenger selectors
- Swap cities
- Flight cards with airline, timings, duration, route and sample fares
- Select a flight, enter traveller details, and show a demo booking reference
- Responsive design for desktop and mobile
- Uses functional components, React state (`useState`), derived results (`useMemo`) and interactive view/state changes

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed in the terminal.

## Important
This is a student demonstration. Flight data is sample data, and no real ticket, reservation, or payment is made.
